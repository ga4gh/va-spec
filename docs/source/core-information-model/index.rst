VA Core Model
!!!!!!!!!!!!!

The **VA Core Model** is a domain-agnostic model for representing scientific knowledge about genetic variation, and the evidence and provenance supporting it. A hierarchical view of the VA Core Model can be found :ref:`here<core-classes>`, along with an overview of modeling principles and patterns that govern its us.
