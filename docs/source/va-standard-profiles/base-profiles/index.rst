.. _base-profiles:

Base Profiles
!!!!!!!!!!!!!

Base Profiles specialize generic VA core classes for a particular type of knowledge through formal definition of concrete subclasses. This approach is used to create `Study Result profiles<study-result-profiles>`_ and `Proposition profiles<proposition-profiles>`_, which can be used/referenced within Statements and Evidence Lines.
