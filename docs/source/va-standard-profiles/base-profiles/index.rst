.. _base-profiles:

Base Profiles
!!!!!!!!!!!!!

Base Profiles specialize generic VA core classes for a particular type of knowledge through formal definition of concrete subclasses. This approach is used to create :ref:`Study Result profiles<study-result-profiles>` and :ref:`Proposition profiles<proposition-profiles>`, which can be used/referenced within Statements and Evidence Lines.
