Major Changes
#############

  * finalizes the Variant Annotation model, with full support for study results, source datasets, and profile metadata
  * establishes VA-Spec 1.0 as the foundational standard for representing variant annotations in research and clinical contexts
  * merges all ``profile-source.yaml`` files into a single, unified source
  * changes the ``pmid`` field type from integer to string, for compatibility across implementations

Minor Changes
##############

  * refines metadata for clarity and consistency across profiles
  * thoroughly updates documentation for v1, including class/attribute descriptions and improved onboarding information
  * streamlines the documentation build process and corrects ReadTheDocs branch handling
