Study Result Data Structure

A class-level view of the Study Result-based structure in VA-Spec data. Italicized text in each class exemplifies the kind of information it may capture — here a Cohort Allele Frequency Study Result reporting gnomAD data about a variant. The cohort link (dashed) is added by that profile, not the base Study Result class.

Study Result
e.g. pop-freq data items about HRAS:c.173C>T: alleleCount=341, alleleFreq=0.002, …
DataSet
the larger data set from which the results data was derived (e.g. gnomAD v3.4.1)
Method
(e.g. curation guides, experiment protocols)
StudyGroup
(e.g. non-Finnish European females)
Document
(e.g. publications, database records)
Contribution
(who, when, and how an agent contributed to an artifact)
Agent
(e.g. persons, organizations, software)
