III.  Community Profiles

Community Profiles are defined as "Schema Compositions" that constrain a core class (rather than subclass it). Statement profiles compose Statement; Evidence Line profiles compose EvidenceLine. Each profile's domain-specificity is set by the Proposition it encapsulates.
