.. _community-profile-sets:

Community Profile Sets
!!!!!!!!!!!!!!!!!!!!!!


**VA Community Profile Sets** are collections of VA Standard Profiles that support the curation and terminological conventions defined by a particular community guideline for generating and describing a particular type of variant knowledge (e.g. the ACMG 2015 guidelines for variant pathogenicity interpretation).

Profile Sets group individual VA Standard Profiles of different types into collections that can be used together to generate data with semantics aligned with a particular community guideline or standard.

For example the ACMG 2015 Profile Set may include a Variant Pathogenicity Statement profile, along with several Evidence Line profiles for describing the different kinds of evidence interpreted to make pathogenicity classificaitons. 


.. _acmg-2015:

ACMG 2015 Community Profile Set
###############################

**Description:**
 - The ACMG 2015 Profile Set includes VA standard Profiles that support representation data generated using  ACMG-based pathogenicity interpretation guidelines or terminologies.
 - At present, this set includes only a **Variant Pathogenicity Statement** profile for representing final classifications of a variant, and an **Experimental Variant Functional Impact Evidence Line** profile for describing how functional  data is interpreted as evidence for these classifications. 
 - As additional ACMG-based Evidence Line profiles are defined for different evidence types, or Study Result profiles defined to represent the foundational data used as evidence, these will be added to this profile set. 

**Profiles Included:**
 - :ref:`Variant Pathogenicity Statement (ACMG 2015)<variant-pathogenicity-statement-acmg-2015>`.
 - :ref:`Experimental Variant Pathogenicity Functional Impact Evidence Line (ACMG 2015)<experimental-variant-pathogenicity-functional-impact-evidence-line-acmg-2015`.
