.. _examples:

Data Examples
!!!!!!!!!!!!!

The **VA-Spec** provides a set of **Profiles** to the GA4GH community as shared schema for describing specific kinds of **Statements**, **Study Results**, and **Evidence Lines** about genetic variation. Implementation of these schema in working systems allows for the **production and exchange of interoperable data**, reporting **diverse kinds of variation knowledge**.

Here we provide a set of **hand-crafted data examples** that have been **annotated** to help readers better understand the **modeling patterns and principles** employed across VA Profiles, to represent variation knowledge and the evidence and provenance supporting it. Additional examples of real data from implementing systems can be found in the `tests/fixtures<https://github.com/ga4gh/va-spec/tree/1.0.0-ballot.2025-03/tests/fixtures>`_ directory.
